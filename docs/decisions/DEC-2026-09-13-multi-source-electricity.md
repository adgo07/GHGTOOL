# 产品决策记录：企业多种电力消费形式

- 决策日期：2026-09-13
- 决策状态：APPROVED
- 决策人：Sol（产品决策与验收）
- 影响阶段：G05、G06

## 背景

企业在同一核算期可能同时使用外购常规电力、外购非化石能源电力、自发自用非化石能源电力，以及自发自用化石能源电力或其他需要单独判断的形式。此前 G05 因 Canonical Source 缺少 GB/T 32151.34—2024 附录 D.1.1 的可追溯零因子而阻塞。

## 决策

1. 电力消费采用多条明细结构，不得设计成企业只能单选一种电力类型。
2. 每条明细独立记录电量、取得方式、电力属性、核算期间、排放因子及来源、证明材料类型和证明状态、参数选择理由及参数快照。
3. 取得方式（外购、自发自用）与电力属性（常规电力、非化石能源电力）是两个独立维度；自发自用不等同于非化石能源。
4. 用户界面统一使用“外购常规电力（电网电力）”，不使用“外购化石能源电力”描述电网混合电力。
5. 外购常规电力采用适用的最新全国电力平均二氧化碳排放因子。
6. 外购非化石能源电力因子为零，前置条件是具备附录 D.2 要求的交易合同及结算凭证或 GEC 等证明。
7. 自发自用非化石能源电力因子为零，前置条件是具备附录 D.2 要求的月度电量原始记录。
8. 自发自用化石能源电力不作为外购电力间接排放重复计算；相关燃料排放进入直接排放路径并接受防重复计算校验。
9. 缺少适用证明时必须产生 `ERROR`，不得采用零因子，也不得静默回退全国平均因子。

## 阶段边界

### G05

- 补录上述 Canonical 参数与因子；
- 提供多电力明细所需的领域上下文和参数解析能力；
- 对每条明细独立解析、独立校验并形成独立快照；
- 增加组合场景：同一企业同时存在外购常规电力、外购非化石能源电力和自发自用非化石能源电力，三条数据必须同时存在且互不覆盖；
- 不制作电力录入页面，不计算企业电力排放总量。

### G06

- 实现多条电力消费明细的增加和删除；
- 每条明细独立选择取得方式和电力属性；
- 按明细分别计算后汇总；
- 防止同一电量在常规电力、非化石能源电力或自发自用燃料路径中重复计算。

## 门禁与执行状态

本决策解除“是否允许新增 Canonical 零因子”的决策阻塞，但不构成 G05 验收通过。记录本决策时未创建 Goal、未实施 G05 或 G06；G06 必须继续等待 G05 正式验收为 `PASS`。
