# HTML V4 到 Qt Widgets 参数映射

本页记录《GHGTOOL 全页面 HTML 交互原型 V4》到现有 PySide6/Qt Widgets 的最小视觉映射，作为 PR2 的实现说明；不新增主题框架。

| V4 设计项 | Qt 实现 |
| --- | --- |
| 页面画布：浅蓝顶部渐变、浅灰蓝正文 | 首页使用 `HOME_CANVAS_GRADIENT`；其余页面使用 `PAGE_BACKGROUND` |
| 品牌深蓝 `#18364F`、正文 `#213A4F`、辅助字 `#698198`、强调蓝 `#197CC2`、边线 `#DAE7F1` | `packages/ui/design_tokens.py` 的应用级 QSS 与首页局部样式 |
| 卡片白底、14 px 圆角、浅边框 | `QFrame#card`、首页入口卡和最近工作卡的局部 QSS |
| 中文界面字体 | Windows 使用 `Microsoft YaHei UI`，回退到 `Microsoft YaHei` |
| 首页 5 个横向入口卡片，标准库为重点卡 | `HomePage`；首页无侧栏，标准库卡片为蓝色强调样式 |
| 首页工作区与最近核算 | `HomePage` 从现有 Project 与不可变 Record 服务读取真实数据；没有数据时显示明确空状态，不使用原型样例数据 |
| 主导航与品牌区 | `AppShell`；侧栏 242 px、品牌区 111 px、导航项 46 px |
| 内容宽度 | 首页最大 1480 px；常规页面最大 1440 px |
| 页面边距 | 常规页面按视口宽度的 3.4% 计算并限制在 22–48 px；首页侧边距 54 px，紧凑窗口下收至 30 px |
| 表格、输入框、选项卡、焦点与悬停状态 | 使用 `application_stylesheet()`，页面仅保留必要的局部覆盖 |
| 下拉箭头 | 保留 V4 下拉控件的箭头样式，使用打包资源 `resources/icons/chevron-down.svg`，由 `scripts/inspect_release.py` 白名单管理 |
| 首页最近核算 | 企业列固定 190 px，周期/状态/日期固定列，操作列填充剩余宽度并右对齐；行高 44 px，完整操作仍可见，企业全名可通过悬停提示查看 |
| 标准库表格 | 标准名称列填充剩余宽度，编号/状态/日期/支持列设定可读宽度；列表正文 13 px、行高 46 px；标准链接默认无下划线，悬停时以下划线和手形光标表示可点击，状态使用与首页一致的标签配色 |
| 参数与因子库 | 复用真实 Catalog 查询，提供“按标准/文件查看”和“全库搜索”两种 V4 模式；不使用 HTML 演示数据 |
| 当前炭素材料模块的八类排放源入口 | 快速定位和八张入口卡由同一来源定义生成；电力、热力分别合并为购入/输出组。这些分组只属于 `GB/T 32151.34—2024` |
| 启用的排放源与物料行 | 来源内容上方使用深蓝标题条；煅烧、焙烧/炭化、石墨化默认展示映射定义的四类物料行，空行可删除且不会转成空物料输入 |

公共页面（首页、导航、标准库、参数库、记录列表与设置）使用中性文案。标准选择只把 `STANDARD_ID` 分发到 `CarbonMaterialAccountingPage`；其他标准继续展示目录信息与“核算未开放”，不会落入炭素材料页面。

验证截图与采集条件见 [V4 页面截图](v4-evidence/README.md)。截图由 Windows 平台 Qt 窗口渲染，使用隔离的测试 Catalog、Project 与冻结 Record 样例。
