# knowledge/ — 碳核算专业知识落点

状态：**ACTIVE / MINIMAL PLACEHOLDER**

本目录保存**可长期复用的碳核算专业知识**，供本仓标准开发、Mapping、Calculator、测试、UI 与 Excel 相关任务顺手沉淀。

## 最小规则

1. 本目录保存可长期复用的专业知识（专业概念解释、参数与数据取得方式、计算与判定解释、标准理解与争议、工程实践建议、常见问题、典型错误、软件字段理解、现场资料取得途径等）。
2. 新条目**默认状态为 `DRAFT`**；未经正式专业审核不得升级为 `REVIEWED` / `PUBLISHED`，AI 生成的知识不得自动成为 `PUBLISHED`。
3. **不强制每个任务生成知识**；不得为了数量制造条目，也不得为了 Knowledge 明显扩大主任务范围。
4. **知识不是 Calculator 真值源**。业务真值链路是 `Standard / Canonical Rule → Calculator → Result`；知识文章只能解释该链路，不得作为 Calculator 的权威数据源或规则源，运行时不得解析 Markdown 知识文章决定业务结果。
5. 每条知识必须区分四个事实层级：**标准原文事实 / 官方资料 / 专业解释 / 工程实践建议**。禁止把技术判断写成标准明文，禁止把工程经验写成强制标准要求；没有发布机构正式解释时不得写成“官方确认”。
6. 具体治理规则（Opportunistic Capture、知识状态、知识最小字段、知识资产位置）见中央 `docs/governance/STANDARD_DEVELOPMENT_GUIDE_V0.1.md` 知识沉淀部分；本目录不复制该指南正文。

## 本落点明确不做

- 不建立复杂 Schema；
- 不建立知识数据库 / SQLite 知识库；
- 不建立向量库 / RAG / AI Chat；
- 不建立知识中心 UI。

当前目录只建立上述最小说明，**尚未登记任何知识条目**。后续条目由真实任务顺手产生，不批量预制。
