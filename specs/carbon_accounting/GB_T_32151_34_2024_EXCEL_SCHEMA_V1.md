# GB/T 32151.34—2024 Excel 模板结构 V1

状态：RS03-A-R1 用户验收候选模板；技术独立验收和用户模板 UAT 待完成。本文件不构成正式标准支持声明。模板由 `packages/excel/gbt32151_34_v1.py` 运行时生成，版本 `1.0.0`，ID `GHGTOOL_GBT_32151_34_2024`。模板 `.xlsx` 不提交仓库或安装包。

一个工作簿对应一个标准，企业和核算期间为工作簿公共信息。工作簿可列出多个全厂、工序或其他核算单元；各单元独立检查、预览，不跨单元合并。普通填写只展示中文业务列名，不要求使用内部 ID。

## 1. 工作表

可见工作表严格为四个：

| 工作表 | 用途 | 主要内容 |
|---|---|---|
| `填写说明` | 说明范围、数值与标准默认值规则，并给出用户验收步骤 | 模板范围、输入规则、常见提示与预览边界 |
| `核算单元` | 维护项目公共信息与核算范围清单 | 企业名称、期间类型、日期、边界确认、公共边界说明；核算单元名称、类型、启用状态、边界说明 |
| `燃料与能源` | 录入燃料、电力和热力业务明细 | B.2 燃料；B.8 电力；B.9 热力 |
| `过程排放` | 录入生产过程与烟气治理明细 | B.3 煅烧；B.4 焙烧/炭化；B.5 石墨化；B.6 烟气焚烧；B.7 烟气脱硫 |

模板另含隐藏的 `__metadata__` 工作表，保存 `template_id`、`template_version`、`standard_id`、`standard_version` 和 `ingress_policy_id`。不得增加单独的普通“排放源”“报告信息”或“证据来源”页；来源说明随相应业务行录入。

## 2. 业务区域与行语义

`燃料与能源` 页按标准业务分为三个独立表格。B.2 包含核算单元、具体燃料种类、体积/质量/热量路径、活动量、标准低位发热量/单位热值含碳量/碳氧化率、实测覆盖值及活动/参数来源。B.8 支持购入或输出电力逐行填写；购入因子由现有参数解析器按期间、属性和证明信息取得，输出电力因子可逐行提供有来源的适用值。B.9 支持购入或输出热力逐行填写，包含热量、蒸汽状态、直接焓值或 C.4/C.5 查表状态，以及对应的实测因子来源。

`过程排放` 页也按标准条款划分区域：

- B.3 煅烧：按物料类别录入待煅烧原料、煅后料、欠烧煅料和炭粉尘；可逐行录入多种物料。软件用现有 Decimal Profile 做质量和固定碳加权归一化，再交给现有 `CalcinationInput` / Calculator。
- B.4 焙烧/炭化：按填充料、待焙烧/炭化品、粉尘/碎屑/副产品和产品逐行录入；归一化到现有 `BakingInput`。
- B.5 石墨化：按保温料/电阻料、待石墨化品、粉尘/碎屑/残块/副产品和产品逐行录入；归一化到现有 `GraphitizationInput`。
- B.6 烟气焚烧：录入流量、焦油含量、低位发热量、含碳量、碳氧化率、运行时间和对应数据来源。
- B.7 烟气脱硫：按脱硫设施/批次与碳酸盐组分逐行录入；必须选择碳酸盐种类。C.2 因子按所选种类自动匹配，不会用 0.44 猜测未知组分。

同一工作表的数据行按“核算单元”关联。存在可解析业务行时，该单元对应排放源状态由入口派生为 `INVOLVED`；没有业务行时为 `NOT_INVOLVED`。活动单元中缺字段、格式无效或内容错误会使该单元校验失败，不能被伪装成“不涉及”。停用单元、未知单元和未关联行不进入计算并给出提醒。

## 3. 标准参考值与来源

- 燃料 C.1 缺省参数从 Canonical 参数/因子目录按具体燃料解析。具体燃料无适用标准值时不猜值；企业实测值只有在填写来源类型与来源说明/编号后才覆盖标准缺省。
- 碳酸盐 C.2 完整支持 Canonical 中全部 11 项标准因子，每项保留标准来源、版本和条款/页码定位。未选种类时阻断计算；合法的用户实测因子必须留有可追溯来源。
- K1/K2/K3 与脱硫剂含量/转化率使用 Canonical 中的标准一般取值；脱硫剂含量 90% 和转化率 100% 是标准允许的缺省值，不是未知碳酸盐因子的替代品。
- 蒸汽 C.4/C.5 查表与插值继续由版本化 Domain Calculator 执行。保留既有已批准压力键口径；模板不创建 reference-table、查表 DSL 或第二套计算公式。
- 活动和实测参数证据按业务行形成 `ActivityDataEvidence` / `MeasuredFactorEvidence`，并在预览中保留工作簿 SHA-256 与工作表/单元格位置。无需维护独立证据登记页。

## 4. 数值、错误隔离与预览

数值规则由 `GHGTOOL_EXCEL_INGRESS_V1.md` 定义：从 OOXML 保存数值词法直接构造 Decimal；拒绝公式、文本数字、日期、布尔值、非有限值、无数值序列化以及超过 15 位有效数字；合法的 0 可用；比例使用实际 `0..1` 数值，不按单元格百分比显示格式换算。下拉列表仅辅助录入，入口仍会复核数据。

结构或模板元数据不可识别时，整个工作簿拒绝导入。其余问题隔离到对应启用核算单元：有效单元交给现有 `CarbonMaterialCalculator` 预览；错误单元显示普通中文原因及工作表/单元格位置，不生成成功结果。导入预览展示燃料、生产过程、烟气治理、购入电力/热力、输出电力/热力分项，以及直接排放、净间接排放和总排放。输出能源显示抵扣量。

RS03-A-R1 仅提供模板与可复核预览，不保存 Project/Workspace、不生成或修改正式 Record、不导出正式报告、不做 Golden Freeze，也不宣称 GB/T 32151.34—2024 已 `SUPPORTED`。RS03-A-R1 实施后等待独立技术验收和用户模板 UAT；RS03-B 仍为 `NOT STARTED`。
