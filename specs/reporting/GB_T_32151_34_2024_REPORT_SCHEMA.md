# GB/T 32151.34—2024 报告 Schema

状态：RPT01 v1.0.0（等待独立验收）。专业业务骨架依据标准第 5.2、7 章及附录 B，并按仓库冻结 Mapping 和 Record 快照语义实现。本文件用于定义软件报告字段，不替代、复制或重新发布标准原文。

## 组织方式

ReportModel 使用 `section → table → row → cell` 结构。Cell 可保存显示值、单位与该值的来源描述；行可附简短说明。过程实例和多物料行属于业务表内容，计算小计只出现在适用过程/来源层级，不把排放量分摊到单件原料。模型由一条正式 Record 的输入、结果、参数、Trace、Provenance、Reporting 和资格快照构建，不重新计算或读取当前 Catalog。

Word 与附录B Excel 输入的共同字段使用一致的中文业务名称、单位和 B.2～B.9 顺序。两种文件职责不同：Word 报告展示冻结结果，Excel 收集B.2～B.9输入并预览；B.1只读展示，不参与活动数据输入。标准表样的列名可按可读性排版，不要求复刻标准页面版式。

## 报告基本信息

| 区域 | 字段 |
|---|---|
| 报告抬头 | 报告主体、核算期间、核算依据、编制日期 |
| 企业与核算情况 | 企业名称、统一社会信用代码、企业性质、所属行业、法定代表人、地址、联系人、编制人、联系电话、核算边界、主要产品及工艺、排放源识别说明、其他说明 |
| B.1 排放汇总 | 直接排放量、净间接排放量、排放总量、记录中可用的各排放源小计 |

可选企业或编制信息没有快照时可以为空。月度/自定义期间资格及重要 WARNING、旧记录快照不足以普通中文提醒呈现，不改变既有记录资格或核算结果。

## 附录 B 业务结构

| 节 | 业务内容与报告字段 | 输入/结果语义 |
|---|---|---|
| B.1 | 温室气体排放量汇总 | 直接、间接、总量及已保存来源小计；全部读取 CalculationResult / Trace |
| B.2 | 化石燃料活动数据和排放因子 | 燃料品种、质量/体积/热量计量路径、活动量及单位、低位发热量、单位热值含碳量、碳氧化率、逐参数来源、燃料排放量 |
| B.3 | 原料煅烧 | 每个煅烧单元下保留待煅烧原料、煅后料、欠烧料、粉尘等实际物料的名称、数量、碳含量/来源、挥发分/来源；Trace 已保存的必要汇总值及该单元排放量；所有单元合计沿用正式记录结果 |
| B.4 | 焙烧/炭化 | 每单元的填充料、待焙烧/炭化品、产品、粉尘/碎屑/副产品等实际行、参数来源、Trace 汇总值和单元排放量 |
| B.5 | 石墨化 | 每单元的保温/电阻料、待石墨化品、产品、粉尘/碎屑/残块/副产品等实际行、参数来源、Trace 汇总值和单元排放量 |
| B.6 | 烟气焚烧治理 | 现有合并口径下的设施输入、适用参数来源与已保存设施排放量；报告层不再次聚合或重算 |
| B.7 | 烟气脱硫净化 | 设施/批次、碳酸盐组分、消耗量、含量、排放因子、转化率、各自来源及既有设施排放量；不在报告层二次求和 |
| B.8 | 购入和输出电力 | 每条电力来源的方向、属性、电量、排放因子、来源及对应排放/抵扣量 |
| B.9 | 购入和输出热力 | 每条热力来源的方向、蒸汽量、饱和/过热类型、绝压、温度、Record 实际采用的焓值与来源、已保存自动参考值、排放因子及来源、对应排放/抵扣量 |

B.2 三个关键参数必须分别表达来源，不能合成一个燃料来源。B.3～B.5 保留原始物料行与各自组成来源；归一化及质量加权结果只取已保存 Trace。B.6/B.7 各保留一张简明业务表，按正式结果展示。B.8/B.9 逐行显示多来源和对应结果。

## 当前Excel输入对应关系

正式输入采用用户批准的附录B母版，工作表按原顺序为B.1～B.9九表；B.1仅是只读结果布局，不作为活动数据输入，不另设说明或隐藏metadata页。B.2～B.9归入同一个Canonical Input，必要期间等上下文由导入页面提供，不将各表分拆成独立核算单元。动态增行按明确业务角色/分组读取，无法无歧义表达时定位错误。

下载精确复制受控无公式资源；不在Excel独立计算排放量。预览不写Record，明确保存项目后由共享Application正式核算。历史EXCEL_R2项目与Record保留原身份和来源快照，无新R2导入路径。具体母版哈希及映射边界见docs/exb01/APPENDIX_B_INPUT_DESIGN.md；不改变Word报告模型/renderer。
